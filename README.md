# Sweet Muse Online Cake Shop

A web-based online cake shop application developed to provide customers with an easy and convenient way to browse cake products, manage their cart, and place orders.

## ✨ Features

- Product browsing and product gallery
- Shopping cart management
- Online order management
- Product management
- CRUD operations
- Customer management
- User-friendly interface
- Database management

## 🛠️ Technologies

- Java
- JSP
- Servlets
- Python
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap

## 🔧 Tools

- NetBeans
- XAMPP
- MySQL Workbench
- Apache Tomcat

## 🎯 Project Purpose

This project was developed as an academic project to gain practical experience in web application development, database management, CRUD operations, and e-commerce application development.
